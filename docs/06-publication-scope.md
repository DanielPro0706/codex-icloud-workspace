# 公开范围与实现边界

本公开仓库从已验证的私有部署源码中逐项提取，建立独立的初始 Git 历史。原私有仓库、线上部署和个人 snapshot 保持原状。

## 包含

- 完整网页 HTML/CSS/JavaScript、目录模板、通知页、Service Worker、PWA 清单、图标和 CSP 响应头。
- 网页部署、选择接口、浏览器身份代理、Web Push helper 与服务器健康/恢复代码。
- 原始阶段性部署脚本、最终 systemd 配置、候选 rclone 补丁/构建/地区测试。
- Cloud 网关客户端、目录绑定、按需获取、计划与写回、精确 Trash 检查、冲突拒绝和备份。
- 可移植定义导出/导入、Mac LaunchAgent、安全快进、Cloud 安装/启动/维护/doctor，以及完整合成测试。
- 从零部署、已发生的错误、实际验收、来源和第三方许可证。

## 不包含

- Apple 密码、session/cookie/token，网关 Basic 值、SSH 私钥、Tailscale enrollment key、GitHub token、邮件 OAuth 和 VAPID 私钥/订阅。
- 原实例 ID、私人域名/IP/邮箱、真实 owner 配置、个人 AGENTS、Skills 快照、聊天数据库、云盘文件、原始日志或截图。
- 没有权利再分发的第三方插件/Skill 内容。需要的开源依赖使用原仓库和锁定版本，并保留许可证。
- 尚未实现或验收的无服务器架构。

## 公开适配

个人域名和固定私有仓库改为显式示例，部署者需在自己的 private 运行 checkout 中替换。邮件收件人改为环境变量，且默认关闭；不能继承原主人的预授权。新增防误执行门禁限制历史 Workbench 包装脚本。测试扫描器改为 PATH 或 `GITLEAKS_BIN`，避免依赖原电脑目录。

这些改动没有同步到原生产部署。公开代码的单元测试与静态检查通过，不等于公开模板已在陌生账户/全新服务器跑过端到端安装。参考脚本保存的是真实建设阶段，部分会安装旧版本或包含当时构建的摘要；从零部署应遵循文档和最终源码，不能批量执行历史脚本。

历史 helper `icloud-rotate-gateway` 会替换网关凭据并重启相关服务；启用前自行补齐保护性备份与恢复安排，确保有独立管理会话。不要在诊断普通网络故障时调用它。
